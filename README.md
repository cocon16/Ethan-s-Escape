# Ethan-s-Escape

## Ethan’s Escape - Gra platformowo-logiczna w 3D

Gra została zrobiona w 3 dni, w roku 2017, aby zaliczyć przedmiot TRW (Techniki Rzeczywistości Wirtualnej. Warto wspomnieć, że przed tymi 72 h nie miałem absolutnie żadnej styczności z robieniem gier w 3d, ani z Unity.

Giera wyszła całkiem grywalna - mimo, że to pierwszy projekt i uczenie się programu.

P.S. Nazwa jest niewyrafinowana - Ethan to była po prostu nazwa gotowego assetu - postaci głównego bohatera.

### Instrukcja

Pobrać (code->download .zip), rozpakować i uruchomić plik **„Ethan's Escape - TRW Piotr Walter”**.

Jeśli ktoś polegnie lub chce sprawdzić zakończenie gry - w stylu gry zręcznościowej - to można uruchomić plik `.exe` z folderu **FINAL SCENE ONLY**.

## Ethan’s Escape — Platform-Puzzle Game

This game was made in 3 days in 2017 as a project for the TRW course (*Virtual Reality Techniques*) at my uni. It’s worth mentioning that before those 72 hours, I had absolutely no experience with 3D game development or Unity.

The game turned out to be quite playable, despite being my first project.

P.S. The name isn’t particularly creative: Ethan was simply the name of the ready-made asset used for the main character.

### Instructions

Download, extract, and run **“Ethan's Escape - TRW Piotr Walter”**.

If you get stuck or just want to see the game's arcade-style ending, run the `.exe` file in the **FINAL SCENE ONLY** folder.

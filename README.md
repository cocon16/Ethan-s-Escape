# Ethan-s-Escape
Gra platformowo-logiczna 3D. Została zrobiona w 3 dni, w roku 2027, aby zaliczyć przedmiot TRW (Techniki Rzeczywistości Wirtualnej. Warto wspomnieć, że przed tymi 72 h nie miałem styczności z robieniem gier w 3d, ani z Unity. Wystarczy rozpakować i otworzyć plik .exe. Ostatni level (zręcznościowy) można bezpośrednio odpalić w "Last scene"
